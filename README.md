# لعبة حروف - موقع جماعي كامل

## التشغيل
1. ثبّت Node.js.
2. افتح مجلد المشروع في Terminal.
3. نفّذ:
   npm install
   npm start
4. افتح المتصفح على:
   http://localhost:3000

## اللعب عبر الإنترنت
ارفع المشروع إلى استضافة تدعم Node.js وWebSocket، ثم شارك رابط الموقع مع اللاعبين.
أنشئ غرفة، ثم شارك رمز الغرفة معهم.

## المزايا
- غرف لعب برمز.
- مضيف ولاعبون.
- فريق أحمر وفريق أخضر.
- لوحة حروف.
- أسئلة مرتبطة بالحروف.
- مؤقت 10 ثوانٍ متزامن من الخادم.
- جرس/زر ضغط؛ أول لاعب يضغط يظهر للجميع.
- المضيف يحدد صحة الإجابة.
- احتساب النقاط وتلوين الحروف.
- تغيير الفريق.
- جولات وإنهاء اللعبة.
